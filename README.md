I build software for high-stakes domains — defence, water governance, critical infrastructure — where the cost of failure is unusually high. Most of my work involves systems that need to be provably correct, not just functional.

---

**GARUDA** — Threat intelligence and autonomous containment platform built for the iDEX programme under India's Ministry of Defence. Combines eBPF kernel instrumentation, hardware side-channel telemetry (Intel RAPL), Bayesian adversary attribution mapped against MITRE ATT&CK, and deterministic containment via DNS sinkholing and process freezing over SSH. Designed to detect state-sponsored intrusion techniques that conventional EDR misses.

**AquaPulse** — Water accounting ledger for collective groundwater governance in rural India. Every number carries an explicit cryptographic provenance tag — live telemetry, satellite replay, or stated assumption — because the system is used by gram panchayats making real allocation decisions. Integrates Sentinel-2 NDVI imagery, Open-Meteo ERA5 weather data, and CGWB hydrogeology. Aligned with Atal Bhujal Yojana and MAHA Water Mission.

**HELMET** — Tactical C2 telemetry platform for the ESP32 Smart Combat Helmet. Renders a 3D digital twin with an aircraft-grade HUD, ingests real-time physiological sensor telemetry over Web Serial, and surfaces physiological stress thresholds derived from MIL-STD-1472H and US Army TB MED 507. Built with zero hardcoded mock values.
