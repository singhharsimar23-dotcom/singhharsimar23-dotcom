**GARUDA** is a threat intelligence and autonomous containment platform built for the iDEX programme under India's Ministry of Defence. It combines eBPF kernel instrumentation, hardware side-channel telemetry (Intel RAPL), Bayesian adversary attribution across MITRE ATT&CK, and deterministic containment via DNS sinkholing and process freezing over SSH — all designed to detect state-sponsored intrusion techniques that conventional EDR misses entirely.

**AquaPulse** is a water accounting ledger for collective groundwater governance in rural India. Every number it displays carries an explicit cryptographic provenance tag — live telemetry, satellite replay, or stated assumption — because the system is used by gram panchayats making real allocation decisions. It integrates Sentinel-2 NDVI imagery, Open-Meteo ERA5 weather data, and CGWB hydrogeology parameters, and is designed for alignment with India's Atal Bhujal Yojana and MAHA Water Mission frameworks.

**HELMET** is a C2 telemetry platform for the ESP32 Smart Combat Helmet. It renders a 3D digital twin with an aircraft-grade HUD, ingests real-time sensor data over Web Serial USB, and surfaces physiological thresholds from MIL-STD-1472H and US Army TB MED 507 — with zero hardcoded mock values.

**Hiremax** is a hiring platform I founded. The problem it addresses is straightforward: structured hiring processes are only accessible to large companies with dedicated HR infrastructure. [hiremax.site](https://hiremax.site)
